# FinPath AI

FinPath AI is a frontend-only prototype for an AI-powered Student Financial & Career Copilot demo.

## Project structure

- `index.html` – landing/dashboard experience
- `profile.html` – student onboarding/profile experience
- `style.css` – visual system and layout styling
- `script.js` – interactions for cards and visual polish
- `src/data` – deterministic frontend-only mock data
- `src/utils` – frontend-only financial and calculation helpers

## Frontend-only quick start

Install dependencies:

```bash
npm install
```

Run the Vite frontend locally:

```bash
npm run dev
```

The application uses local mock data and browser state only. No PostgreSQL, Prisma, Python, FastAPI, database, or API key integration is required.
